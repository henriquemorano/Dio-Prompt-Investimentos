# 🎯 Desafio Criativo: Extraindo Insights do Feedback de Clientes Bancários

## Prompt Final Refinado

**Atue como** cientista de dados e especialista em comportamento do consumidor bancário.

**Sua tarefa é analisar** uma base de tickets de suporte e avaliações de lojas de aplicativos sobre **a plataforma de investimentos e previdência privada** para identificar **gargalos na jornada do usuário e dúvidas recorrentes.**

**Contexto:** O resultado será utilizado pela diretoria de produtos de investimento para priorizar melhorias na interface do aplicativo e treinar os assessores financeiros. O objetivo é reduzir a taxa de abandono na contratação de novos produtos.

**Dados disponíveis:** Planilha contendo ID do cliente (anonimizado), faixa etária, produto de investimento citado, texto do comentário, data e tempo de resposta do suporte.

**Instruções de análise:**
* Classifique os feedbacks por complexidade da dúvida, sentimento (positivo/negativo/neutro) e produto (Renda Fixa, Ações, Previdência).
* Identifique os principais atritos na jornada de contratação e navegação.
* Aponte evidências nos dados, destacando padrões por faixa etária, se houver.
* Sugira 3 ações práticas de UX/UI (Experiência e Interface do Usuário) para a equipe de tecnologia.

**Formato da resposta:** Entregue um relatório estruturado contendo um parágrafo de visão geral, uma tabela cruzando 'Produto x Principal Problema x Sentimento', e uma seção detalhada de 'Plano de Ação'.

**Restrições:**
* Use apenas os dados fornecidos.
* Não invente números, causas ou conclusões.
* Não exponha dados pessoais ou sensíveis sob nenhuma hipótese.
* Informe limitações quando os dados não forem suficientes para uma conclusão segura.
* Use linguagem executiva, direta e analítica.
